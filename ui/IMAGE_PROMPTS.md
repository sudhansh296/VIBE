# VIBE: Image prompts

Paste each prompt into Gemini / ChatGPT / Midjourney / Leonardo. Save the result with the file name shown, in `C:\VIBE\ui\assets\icons\`.
If the tool supports a **negative prompt**, paste the negative prompt too. Otherwise add it at the end as "Avoid: …".

**Tip:** Upload one of your existing ghost icons (`home.png`, `chat.png`, `profile.png`) as a reference image along with the prompt. That keeps all ghosts in the same style.
